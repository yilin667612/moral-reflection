# Supplementary Materials

This repository contains the supplementary materials for **“Beyond Agreement: Promoting and Evaluating Reflection in AI Moral Advice,”** submitted to the **ACM Conference on Fairness, Accountability, and Transparency (FAccT 2027)**.

## Anonymized Preregistration

The anonymized preregistration is available [here](https://osf.io/scpy6/overview?view_only=4a1fde23da204201a99dfa1dcfe84d98).

## Survey Materials

This folder contains screenshots of the surveys used in the Actor and Observer studies.

## Experimental Materials

This folder contains the six moral dilemma scenarios and their corresponding AI-generated responses across the four experimental conditions: Affirming, Opposing, Balanced, and Socratic.

## Additional Analyses

This folder contains supplementary analysis results not included in the main paper.
